# Vimeo 動画をローカルに保存する

期限付きで共有された Vimeo 動画（パスワード付き）を、期限が切れる前に MP4 として PC に保存するためのスクリプトです。
中身は定番のオープンソースツール [yt-dlp](https://github.com/yt-dlp/yt-dlp) と ffmpeg を自動で取ってきて実行するだけです。

> **期限が切れたら保存できなくなります。見られるうちに実行してください。**
> 保存した動画は個人で見るためだけに使い、再配布はしないでください。
> このリポジトリは公開設定なので、**パスワードや URL はファイルに書かず**、実行時に入力する形にしています。

---

## Windows

1. `download_windows.bat` をダウンロードして、適当なフォルダ（例: デスクトップに新しいフォルダ）に置く
2. ダブルクリックで実行
   - 「Windows によって PC が保護されました」と出たら **詳細情報 → 実行** を押す
3. 黒い画面で次の順に入力する
   - `URL 1:` → 前半の URL を貼り付け（右クリックで貼り付け）→ Enter
   - `URL 2:` → 後半の URL を貼り付け → Enter
   - `URL 3:` → **何も入れずに** Enter
   - `Vimeo password` → パスワードを入力 → Enter
4. 終わると `videos` フォルダが自動で開きます（`1 - タイトル.mp4`, `2 - タイトル.mp4`）

## Mac

1. `download_mac.sh` をダウンロード（「ダウンロード」フォルダに入る想定）
2. 「ターミナル」アプリを開いて、次を貼り付けて Enter
   ```
   bash ~/Downloads/download_mac.sh
   ```
3. 入力の仕方は Windows と同じ（URL 2 本 → 空 Enter → パスワード）
4. 終わると `~/Downloads/videos` が Finder で開きます

---

## 目安

- 3 時間ぶんで **数 GB**（1080p 上限で保存）。空き容量に 10 GB 以上の余裕を。
- 時間は回線次第で 10〜30 分程度。途中で止まっても、**もう一度実行すれば続きから再開**します。

## うまくいかない時

1. **もう一度実行する** — 実行のたびに yt-dlp を最新版に更新するので、それで直ることがあります。
2. **Vimeo のページに「ダウンロード」ボタンがないか見る** — 投稿者が許可していれば動画の下に出ます。
3. **cookies.txt を置いて再実行する（Vimeo にログインした状態で取得）**
   - 無料の Vimeo アカウントを作って、Chrome でログインする
   - Chrome 拡張「[Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)」を入れる
   - vimeo.com の動画ページを開いてパスワードを入れ、再生できる状態にする
   - 拡張のアイコン → **Export** で保存したファイルを `cookies.txt` という名前にして、スクリプトと同じフォルダに置く
   - スクリプトをもう一度実行（URL とパスワードは同じ）。最初の方法が失敗すると、自動で cookies.txt を使って再試行します
   - ※ cookies.txt はログイン情報そのものなので、人に渡さず、終わったら削除してください
4. **画面録画（最終手段・確実）** — ブラウザで再生しながら録画します。実時間（前後半で計 3 時間）かかります。
   - [OBS Studio](https://obsproject.com/ja)（無料・Windows/Mac 両対応）を入れる
   - 「ソース」に **ウィンドウキャプチャ**（ブラウザ）と、音声用に **アプリケーション音声キャプチャ**（Mac は「画面キャプチャ」で音声も取れます）を追加
   - 動画を全画面で再生 → 「録画開始」→ 終わったら「録画終了」
   - 録画中は PC がスリープしないよう、電源設定でスリープを「なし」にしておく
   - ※ Mac 標準の画面収録（⌘+Shift+5）は**動画の音が録れない**ので OBS を使ってください
